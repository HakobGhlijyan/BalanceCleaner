# Локализации сайта

Здесь хранятся переводы интерфейса и текстов сайта. Рабочий переключатель языка находится в `index.html`, а эти файлы служат единственным местом хранения переводов для дальнейшего редактирования.

Поддерживаемые языки:

- `en.json` — English
- `fr.json` — Français
- `es.json` — Español
- `it.json` — Italiano
- `de.json` — Deutsch
- `ru.json` — Русский

Не храните здесь персональные данные или секреты.
